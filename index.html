Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Ensemble de pages et sites accessibles sur Internet. On les consulte avec un navigateur.

Internet

Grand réseau mondial qui relie les ordinateurs et appareils. Il permet d’échanger des données.

Cloud

Service permettant de stocker des données sur des serveurs distants. On y accède par Internet.

W3C

Organisation qui définit des standards pour le Web. Elle aide à rendre le Web compatible et accessible.

Partie 2 - Distinguez les langages du Web

Langages client

Langage exécuté sur l’appareil de l’utilisateur. Exemple : JavaScript.

Navigateurs

Logiciel permettant de consulter des sites Web. Exemple : Chrome, Safari ou Firefox.

Langages serveur

Langage exécuté sur un serveur. Il permet de traiter les demandes des utilisateurs.

Frameworks

Ensemble d’outils facilitant la création d’un logiciel ou d’un site. Exemple : React.

Bases de données

Système permettant de stocker et organiser des informations. Exemple : comptes ou produits.

Site responsive

Site qui s’adapte à la taille de l’écran. Il fonctionne sur ordinateur, tablette et téléphone./p>

Application mobile

Programme conçu pour fonctionner sur smartphone ou tablette. Exemple : WhatsApp.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Ordinateur qui fournit des données ou services à d’autres appareils. Il peut héberger un site Web.

Adresse IP

Numéro permettant d’identifier un appareil sur un réseau. Elle permet aux appareils de communiquer.

Nom d’hôte et DNS

Nom permettant d’identifier un appareil ou serveur sur un réseau. Il est plus facile à retenir qu’une IP. Système qui traduit un nom de domaine en adresse IP. Il permet de trouver le serveur d’un site.

Protocoles

Ensemble de règles permettant aux appareils de communiquer. Exemple : HTTP ou HTTPS.

Partie 4 - Identifiez les métiers du web

Développeurs

Personne qui crée des sites, applications ou logiciels. Elle écrit et maintient du code.

Product Managers et chefs de projets

Personne qui définit les objectifs et fonctionnalités d’un produit. Elle suit son évolution.Personne qui organise et coordonne un projet. Elle suit les tâches, délais et équipes.

Designers

Personne qui travaille sur l’apparence et l’utilisation d’un produit. Elle crée notamment les interfaces.

Testeurs

Personne qui vérifie qu’un logiciel fonctionne correctement. Elle recherche et signale les bugs.

Techniciens informatique

Personne qui installe et dépanne le matériel informatique. Elle aide aussi les utilisateurs.

Boîte à outils du développeur

  • IDE comme VS Code : Logiciel qui permet d’écrire, organiser et tester du code. VS Code est un IDE très utilisé.
  • Github : Plateforme permettant de stocker du code et de travailler à plusieurs sur des projets. Elle utilise notamment Git pour suivre les modifications.
  • Librairies / bibliothèques :Ensemble de codes déjà créés que le développeur peut utiliser dans son projet. Elle évite de tout programmer soi-même.
  • Frameworks : Un framework est une structure qui facilite la création d’un site ou d’une application. Exemples : React avec JavaScript, Django avec Python et Laravel avec PHP. Il fournit des outils et une organisation qui permettent de développer plus rapidement.
